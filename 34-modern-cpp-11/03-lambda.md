# Lambda Expressions

C++11 introduced lambda expressions for creating anonymous callable objects.

## Basic Syntax

```cpp
auto add = [](int a, int b)
{
    return a + b;
};

std::cout << add(2, 3);
```

General form:

```cpp
[capture](parameters) -> return_type
{
    // body
}
```

The return type can often be omitted.

## Capture by Value

```cpp
int x = 10;

auto f = [x]()
{
    std::cout << x;
};
```

The lambda stores a copy of `x`.

## Capture by Reference

```cpp
int x = 10;

auto f = [&x]()
{
    x++;
};
```

The lambda refers to the original `x`.

## Capture All

```cpp
[x, y]() { }
[&x, &y]() { }

[=]() { } // capture used local variables by value
[&]() { } // capture used local variables by reference
```

## `mutable`

A by-value capture is normally treated as const inside the lambda:

```cpp
int x = 10;

auto f = [x]() mutable
{
    x++;
};
```

The lambda's stored copy can now be modified.

## Generic Lambdas

Generic lambdas were introduced in C++14, not C++11:

```cpp
auto print = [](const auto& value)
{
    std::cout << value;
};
```

## Lambda Type

Every lambda has a unique unnamed closure type.

You normally use:

```cpp
auto lambda = [] {};
```

or store it in:

```cpp
std::function<void()> f = [] {};
```

## Interview Point

A lambda is an object with an `operator()` generated by the compiler; it is not simply a function pointer.
